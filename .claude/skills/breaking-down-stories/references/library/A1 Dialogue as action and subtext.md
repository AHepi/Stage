# A1. Dialogue as Action: What McKee's *Dialogue* Means for Staging

> **What this file is for**
> 1. It turns Robert McKee's *Dialogue: The Art of Verbal Action for Page, Stage, and Screen* (2016), Parts One and Two, into screen decisions for the scene-by-scene breakdown.
> 2. Use it at the step where the pipeline reads a scene's talk and decides whose face we see, what hands and props do, where a pause holds and where a cut falls.
> 3. Input: one scene (screenplay or prose) already split into beats. Output: a scene-level geography (who is screen left and right) plus per-beat fields: action, unsaid, landing face, activity, carrier, pause/sound, cut rule, flaw flags.
> 4. Core idea: every line is an action. The camera films the action and where it lands, not the words.
> 5. Read "Terms" first, then run the Procedure (section 7) and Checklist (section 8), using the Translation Table (section 5) and Decision Rules (section 6, including its precedence order and tie-breaks) to choose shots.

---

## 1. Why this file exists

McKee's book is written for writers. It tells them how to make talk carry desire, conflict and change beneath its surface. It says very little about what a director, a cinematographer or an editor should do with that talk. This pipeline needs exactly that missing half. Our input is already written, and our job is to decide how it should look and sound.

The bridge is McKee's founding claim, set out in Chapter One: dialogue is *action*. A character who speaks is doing something to someone: pleading, warning, punishing, deflecting. If that is true, then a scene of talk is a scene of events, and every event has a doer, a receiver and a result. A camera can show all three. Most of the craft in this file comes down to three questions asked of every line:

1. **What is the speaker doing?** This is the action, named with a verb.
2. **Where does it land?** Which face, hand or object changes because of it?
3. **What is not being said?** How can the audience see it without anyone saying it?

The words themselves are the least of it. McKee's warning to writers, "Dialogue problems are story problems" (Chapter Four, repeated in Chapter Nine), has a staging twin: shooting problems in dialogue scenes are almost always *action* problems. The shot list is weak because nobody decided what each line was doing.

## 2. Terms used in this file

Each term below is used with one meaning only. Where the file uses two words for the same idea (gerund / action verb; receiver / listener / target), the table says so.

| Term | Plain definition |
|---|---|
| **Dialogue** | McKee's definition: "Any words said by any character to anyone" (Ch. 1). That covers talk to others, talk to oneself, and talk to the audience or reader. |
| **Line** | One character's uninterrupted speech in the script, from when they start talking to when someone or something else takes over. |
| **Action** | What a character is really doing through a line or a gesture, named as an "-ing" verb: *warning*, *begging*, *deflecting*. McKee asks writers to label the action this way (Ch. 2). |
| **Gerund** | A verb ending in "-ing" used as the name of an action (*warning*, *refusing*). This file uses "gerund" and "action verb" for the same label. |
| **Receiver** | The character (or object) a line is aimed at. Also called the listener; when a fact is fired as a weapon, the receiver is called the target. |
| **Activity** | The visible surface behavior (talking, eating, fixing a machine) through which an action is carried out (Ch. 3). |
| **Text** | What is actually said and done on the surface (Ch. 3). |
| **Subtext** | The thoughts, feelings, desires and actions that flow beneath the text, conscious and unconscious (Ch. 3). |
| **The said / the unsaid / the unsayable** | McKee's three layers of a character (Preface, Ch. 3). The said is what they choose to say. The unsaid is what they think and feel but hold back: in McKee's words, what a character "expresses in an inner voice but only to himself" (Preface). The unsayable is what they cannot put into words even to themselves, because it is unconscious. Test for the breakdown: if the character *could* say it but chooses not to, it is unsaid; if the character does not know it, it is unsayable. |
| **Beat** | One exchange of action and reaction: one character does something, and someone or something reacts (Ch. 9; fully defined in McKee's Ch. 12). |
| **Value** | The thing at stake in a scene that can swing positive or negative, such as trust/betrayal or alive/dead. |
| **Turning point** | The beat where the scene's value changes charge. |
| **Exposition** | The facts about setting, history and character that the audience needs in order to follow the story (Ch. 2). |
| **Exposition as ammunition** | McKee's technique of having characters use a fact as a weapon or a tool in a fight, so the audience absorbs it without noticing it was told (Ch. 2). |
| **Third thing** | McKee's term for the object, person or idea through which two characters route their conflict, so that they never argue about the real problem head-on (Ch. 8). |
| **On-the-nose** | Dialogue in which a character says exactly and fully what they think and feel, leaving nothing underneath (Ch. 8). |
| **Duelogue / trialogue** | McKee's terms (Ch. 8). A duelogue is two characters arguing directly and explicitly about their immediate problem. A trialogue is the same conflict routed through a third thing. (Do not confuse "duelogue" with "duologue," McKee's ordinary word for any two-person talk, Ch. 1.) |
| **Core word** | The word or phrase that carries a line's meaning; McKee also calls it the key term (Ch. 5). Where it sits in the line decides the line design. |
| **Plant / payoff** | A plant is a detail shown or said early so that a later moment (the payoff) makes sense when it arrives. |
| **Paralanguage** | Everything besides the words that carries meaning: face, gesture, posture, pitch, pace, volume, and the distance between bodies (Ch. 5). |
| **Microexpression** | A facial expression that flashes across the face for a fraction of a second, often before the person can hide it. |
| **Proxemics** | The distances characters keep from each other, and what those distances mean. The term comes from the anthropologist Edward T. Hall; McKee lists proxemics under gesture (Ch. 2, citing Hall's *The Silent Language*) and under paralanguage (Ch. 5). |
| **Landing face** | *(This file's term.)* The face on screen at the moment a line's key word lands. Choosing it is the most important camera decision in a dialogue scene. |
| **Carrier** | *(This file's term.)* An object, body part, place or sound that the breakdown assigns to hold something the dialogue does not say. |
| **Shot** | One continuous piece of film between two cuts. |
| **Hold** | Letting a shot run without cutting. |
| **Reaction shot** | A shot of a character listening or reacting rather than speaking. |
| **Insert** | A close shot of an object or a body part, such as hands, a key or a screen. |
| **Single / two-shot / over-the-shoulder (OTS)** | A single shows one character. A two-shot frames two characters together; it gives them equal weight only if they are the same size and equally lit. An OTS looks at one character past the back of another character's shoulder or head. A "clean" single has no one else in frame; a "dirty" single has a sliver of the other character's shoulder or head at the frame edge. |
| **Coverage** | The set of shots filmed of one scene from different angles, from which the editor builds it. |
| **Split edit** | A cut where picture and sound change at different moments. In a **J-cut** the next shot's sound starts before its picture (we hear a line before we see its speaker). In an **L-cut** the sound of the outgoing shot carries on over the next picture (a line goes on after we have cut away to the listener). |
| **Frame within a frame** | Composing a character inside a doorway, window, mirror, screen or glass pane that is itself inside the shot. |
| **Room tone** | The quiet background sound of a space, used in place of dead digital silence. |
| **Dramatized / narratized** | Dramatized dialogue is acted out inside a scene. Narratized dialogue is spoken outside the scene: voice-over, direct address to camera, or first-person narration (Ch. 1). |
| **Soliloquy / aside** | Stage terms: a soliloquy is a character speaking their thoughts aloud, alone or to the audience; an aside is a brief remark to the audience that other characters on stage are taken not to hear (Ch. 1). |
| **Voice-over (V.O.) / off-screen (O.S.)** | V.O. is a voice not physically present in the scene's space, such as narration or a radio. O.S. is a voice present in the space but outside the frame. |
| **Nonrealism** | McKee's umbrella for genres that abstract or exaggerate life: fantasy, science fiction, musical, animation, horror, farce, myth and similar (Ch. 4, Ch. 8). |

**Camera, sound and editing terms used below.** Each is defined once here.

| Term | Plain definition |
|---|---|
| **Wide / medium / medium close-up (MCU) / close-up (CU)** | Shot sizes. A wide shows the whole body and the space. A medium cuts at the waist. An MCU cuts at the chest, so the eyes read clearly. A CU fills the frame with the face. |
| **Point-of-view (POV) shot** | A shot that shows what a character sees, from where they stand. |
| **Push-in** | The camera moves slowly toward a subject, so the frame tightens during the shot. |
| **Tilt** | The camera pivots up or down from a fixed position. |
| **High / low angle** | The camera looks down at a subject from above eye level (high) or up at it from below eye level (low). |
| **Profile** | A face seen side-on. |
| **Lens length** | A wide (short) lens shows more space and exaggerates distance between near and far; a long lens shows less space, flattens distance and makes backgrounds crowd in. |
| **Deep staging** | Placing characters at different distances from the camera (one near, one far) in a single frame so the audience sees action and reaction without a cut. |
| **Rack focus (focus pull)** | Shifting sharp focus from one subject to another within a shot, which moves the audience's attention without a cut. "Soft" means out of focus. |
| **Axis of action (the 180-degree line)** | An imaginary line drawn through the two characters who are talking. Keeping every camera on one side of it keeps each character facing the same screen direction from shot to shot. |
| **Eyeline** | The direction a character looks, relative to the lens (for example, "looking screen right, just past the lens"). Matching eyelines make two separate singles read as two people looking at each other. |
| **Shot / reverse shot** | The standard way to cover a conversation: a shot of A looking one way, then a shot of B looking the opposite way, cut back and forth. |
| **Score / diegetic sound** | Score is music added for the audience that the characters cannot hear. Diegetic sound exists inside the scene's world (a radio, a pump, footsteps). |
| **Mix** | The balance of all sound layers. "Low in the mix" means quieter than the other sounds. |
| **Pre-lap** | A J-cut used across a scene change: the next scene's sound (often its first line) starts under the end of the current scene. |
| **Montage** | A run of short shots that compresses time or summarizes events, usually without synchronized dialogue. |
| **Previs** | "Previsualization": a rough 3D or animated mock-up of the shots, made before final production to test framing, timing and movement. |

## 3. McKee's working ideas, extracted (Parts One and Two)

This section summarizes the ideas the pipeline uses, in McKee's order, with the chapter each comes from. Most of it is paraphrase. Short quotes are marked.

### 3.1 The full definition of dialogue (Chapter One)

- **Three tracks.** Characters talk to others, to themselves, and to the reader or audience. McKee counts all three as dialogue for two reasons. Each needs a character-specific voice. And "all speech is an outward execution of an inner action." No one talks "for no reason, to do nothing."
- **Words are deeds.** McKee borrows J. L. Austin's term *performative*, meaning words that perform a task, and states his foundation: "Dialogue-as-action is the foundation principle of this book." Each line moves the scene from one beat to the next. It also moves the speaker toward or away from what they most want.
- **Every monologue is a dialogue.** A character alone is arguing with another part of themselves. A narrator is working on the audience, perhaps to win its forgiveness or to prejudice it against someone.
- **Dramatized versus narratized.** Dramatized dialogue happens inside scenes. Narratized dialogue steps outside them, as soliloquy and aside on stage, or voice-over and direct-to-camera address on screen.
- **Medium matters.** McKee calls theatre primarily auditory, so it favors voice over image. Film is primarily visual, so screenplays "favor image over voice." Television sits between the two. Prose is a mental medium, where the reader has to imagine the sights and sounds.
- **Indirect dialogue.** A character or narrator can summarize earlier talk instead of acting it out. McKee gives two examples. In Bruce Norris's play *Clybourne Park*, Bev paraphrases her husband, so the audience hears *her interpretation* of what he said rather than his words. In Franzen's novel *The Corrections*, the narrator repeats "Enid suggested..." five times, pushing a marital argument to the edge of farce. McKee adds that summary lets the reader imagine a more personal, believable version of what might have been heated, melodramatic talk if quoted directly.
- **One screen case.** McKee describes a letter in Ingmar Bergman's *Winter Light* (1963). The woman who wrote it speaks it straight to camera in close-up while her ex-lover reads, for what McKee calls "six uninterrupted minutes." It is a narratized speech staged as subjective camera.

### 3.2 The three functions: exposition, characterization, action (Chapter Two)

**Exposition.**
- *Pacing and timing.* Pacing is how often facts are fed in. Timing is the exact scene and line that reveals a given fact. Too little exposition confuses. Too much too early stalls the story and gives away the turning points. McKee suggests ranking every fact by importance. Critical facts may need to be planted more than once, and minor ones need only a hint.
- *Showing versus telling.* Telling makes characters stop pursuing what they want in order to explain. McKee adds that "telling erases subtext." His dry-cleaner example rewrites a line of reminiscence ("how long have we known each other now?") as an insult to a stoned partner. The facts ("twenty years," "school") slip in while the audience's eye goes to Harry to catch his reaction.
- *Narrative drive.* Facts that raise questions pull the audience forward, so it never feels it is being told anything. McKee's example is the Catch-22 exchange.
- *Exposition as ammunition.* Characters use what they know as weapons in the fight to get what they want. McKee's example is Vader's "I am your father" in *The Empire Strikes Back* (1980), a fact deployed in the middle of a duel.
- *Revelations and backstory.* The most important facts are usually secrets. They come out when a character faces a choice between two evils. McKee narrows *backstory* to mean past, usually secret, events revealed at key moments to push the story forward. It does not mean the character's whole life history. His example is George's invented telegram in *Who's Afraid of Virginia Woolf?*
- *Direct telling.* Narration has two virtues: speed and counterpoint (a narrator who ironizes or contradicts the drama, as in *The French Lieutenant's Woman*). But filmic narration that pumps out "and then... and then... and then" exposition substitutes "the easy work of telling for the arduous task of showing." McKee offers two conversions: *interpolate a scene* (the narrator acts out a remembered exchange instead of summarizing it) or *generate inner conflict* (the narrating character argues with himself). Both are useful when the breakdown must decide what to do with voice-over (R32).
- *Forced exposition.* This means headlines, convenient TV broadcasts, title crawls, or characters telling each other things they both already know. McKee draws a distinction. A quick visual telling (an opening title roll, a place-and-date caption, "a cogent image or a quick-printed fact") is forgiven: "a little telling goes a long way." But audiences "will not forgive a deluge of facts artlessly shoehorned into dialogue," and his example of that is the couple asking "how long have we known and loved each other now?" For staging, this means a forced fact is safer as a brief image than as a line.

**Characterization.** *True character* is who a person is, and it shows only in choices made under pressure. *Characterization* is the surface: every observable trait. Characterization has three jobs: to intrigue, to convince, and to individualize. Its most individual trait is how the character talks.

**Action.** McKee names three kinds:
- *Mental*: a thought that changes the character.
- *Physical*: either *gestures* (all body language, which can modify speech or replace it) or *tasks* (activities that get something done).
- *Verbal*: here McKee quotes Elizabeth Bowen, "Dialogue is what characters do to each other."

Before writing a line, McKee asks three questions: what does my character want, what action would she take now, and what exact words would carry it out. His exercise is to label the subtextual action of famous lines with gerunds. For example, Macbeth's "Tomorrow and tomorrow..." becomes *denouncing existence*, and Rick's "Of all the gin joints..." becomes *lamenting lost love*.

### 3.3 Content: the said, the unsaid, the unsayable; action versus activity; text and subtext (Chapter Three)

- **Three nested spheres.** The unsayable churns at the center, the unsaid is held back around it, and the said is let out at the surface. The audience looks past the said to sense the unsaid. The unsayable only shows in choices. "Language... cannot express who a character actually is, only who he seems to be." Yet talk is itself a deed, so under pressure it reveals true character.
- **Action versus activity.** "Nothing is what it seems." Playing cards, sipping wine and, "most of all, talking" are activities. The action runs beneath them. McKee's ice-cream example: the eater may be drowning sorrows, rebelling against a doctor, or rewarding himself. Two points are key for staging:
  - "Even silence has underlying action." Refusing to speak can be a cruel act.
  - "When a character pauses, she's either reacting to the scene's previous action or preparing her next move."
- **Text and subtext.** Good dialogue creates a "transparency." The words hide the speaker's inner life from the other characters while letting the audience see through to it. McKee's example: "Hi, how ya doing? Oh look, you've lost weight!" could be encouraging, seducing, taunting or insulting, depending on the history between the two people. McKee also notes that paralanguage, dress and movement shape how a character expresses himself "with or without words."

### 3.4 Form: the conflict complex and the media (Chapter Four)

- **Four levels of conflict.** Physical (time, space and everything in them), social (institutions and the people in them), personal (friends, family, lovers) and private (conscious and unconscious thoughts and feelings). McKee himself also calls the private level "inner conflict" in the same chapter; this file uses "private" throughout, and "inner" in the brief means the same thing.
- A story pitched at one extreme level only is *complicated* but not *complex*. McKee's examples are J. C. Chandor's *All Is Lost* (2013) for pure physical conflict and *Mrs. Dalloway* for pure inner conflict. Complex stories use two or more levels. Often they use private conflict and physical strife as the outer brackets and concentrate on the two middle levels, personal and social, which McKee calls "the two venues of talk."
- **The quantity rule.** "The more physical and social a story's conflicts, the less the dialogue; the more personal and private the conflicts, the more the dialogue."
- As people move from personal to social relationships, McKee says, they speak "with less sincerity and greater formality," and when public conflict peaks, characters "break into speeches."
- **Film.** The big screen "foregrounds images and backgrounds sounds," so audiences take the story in through their eyes while they "half listen" to score, effects and dialogue. The camera and microphone "magnify and amplify behavior," so falseness shows. Screen dialogue has to feel spontaneous, and ornamented lines make even fine actors sound ludicrous. McKee lists three exceptions: stylized realism (an unfamiliar world or period), nonrealism (science fiction, musical, animation, fantasy, horror, farce) and extreme characters (larger-than-life talkers). His rule is "always write for the actor." He also warns against improvised "echo chamber" repetition.
- **Television.** The small screen pulls the camera into close-ups, "and when it does, that face talks."
- **Prose.** Novelists put their richest language into narration, not into quoted dialogue. McKee separates *stream of consciousness* (a third-person voice imitating a mind) from *inner dialogue* (a character talking to himself in first or second person). His summary: stage dialogue is the most embellished, screen dialogue the most concise, prose dialogue the most mutable.

### 3.5 Technique: figures, paralanguage, line design, economy, the pause, silence (Chapter Five)

- **Figurative language.** The more sensory the figure of speech, the deeper and more memorable it is: "sour" beats "lousy." Blanche's "Sometimes—there's God—so quickly" packs a whole life pattern into five words.
- **Paralanguage.** Actors provide it on stage and screen. McKee says the eye reads microexpressions "at up to one twenty-fifth of a second," citing Gladwell's *Blink* in his notes. On the page, paralanguage has to be described.
- **Adaptation.** "The camera cannot photograph thought." Inner dialogue cannot be carried sideways from page to screen. The adapter has to reinvent it, turning narratized dialogue into dramatized dialogue.
- **Line design.** Every line has a *core word*, the word that carries its meaning. There are three designs:
  - *Suspense (periodic)* puts the core word last. It is the most dramatic and the most comic design.
  - *Cumulative* puts the core word first and adds detail after it. It feels conversational.
  - *Balanced* puts the core word in the middle.

  McKee also names *parallel* designs, which link phrases of similar length for contrast ("When I walked into that church, I walked into a new life"). Any single design used constantly becomes "as repetitious as wallpaper," so a good scene mixes them (Ch. 5). In Chapter Nine he adds the performance consequence: speeches that *end* on a cumulative sentence cause miscues, because the other actor has already understood and must wait.
- **Economy.** Say the most in the fewest words. McKee quotes Strunk and White's "Omit needless words."
- **The pause.** A pause *before* a turning point dams up tension. A pause *after* one lets the audience absorb the change. Overuse kills the effect: "There are no free rests: A pause must be earned."
- **The case for silence.** When a scene over-talks, write for the eye. Replace talk with (1) paralanguage, such as a nod or a glance instead of "I agree," or (2) physical action. "Silence invites the camera in. Use it." McKee's example is a scene from Bergman's *The Silence* (1963). As he describes it, a waiter drops a napkin beside a woman's chair and smells her as he stoops to pick it up. The seduction turns on her inhale. "Silence is the ultimate economy of language."

### 3.6 The six tasks of dialogue (Introduction to Part Two)

Every exchange should do six things at once:

1. Take an inner action.
2. Build the scene beat by beat toward and around its turning point.
3. Convey exposition.
4. Characterize the speaker through a unique voice.
5. Carry the audience on narrative drive.
6. Stay credible to the character and the world.

### 3.7 The flaws and McKee's fixes (Chapters Six to Nine)

| Flaw (chapter) | McKee's diagnosis | McKee's fix |
|---|---|---|
| **Incredibility** (6) | Talk untrue to character, setting or genre. Actual everyday chatter is no cure, because "Dialogue concentrates meaning; conversation dilutes it." | Judge by fictional authenticity, not factual accuracy. Match outer tactic to inner motive. |
| **Empty talk** (6) | No motive can be found in the subtext. The classic case is telling someone what they already know. | Give the line a reason inside the scene, or cut it. |
| **Overly emotive talk** (6) | The language is bigger than the feeling. | Match emotion to what is at stake. |
| **Overly knowing / overly perceptive talk** (6) | The author's research or insight leaks into a character's mouth. | Keep a line between author and character. Beware characters whose self-insight exceeds "Freud, Jung, and Socrates combined." |
| **Excuses mistaken for motivation** (6) | A childhood trauma pasted on as the "reason." | Separate motivation (needs) from justification (excuses). Characters voice excuses, and the motivation stays buried. Richard III's "cannot prove a lover" is an excuse. |
| **Melodrama** (6) | "Not over-expression but under-motivation." | Raise the motivation to match the behavior. Then ask whether the character would *state* or *understate* it. The whispered "Crucify him" shows more power than a screamed catalogue of tortures. |
| **Clichés, character-neutral, ostentatious, arid language** (7) | Stock phrases, lines anyone could say, showy writing that breaks belief, and dry Latinate speech. | Use the concrete, the familiar, short words, the active voice, direct phrasing and short speeches. Cut clutter. "If your dialogue does not suggest unsaid thoughts and feelings below its surface, either enrich it or cut it." McKee also notes that under rising conflict people get more emotional, direct and monosyllabic. |
| **On-the-nose** (8) | Putting a character's full thoughts and feelings directly into words, so subtext disappears. It is "unactable." | Give the scene a hidden action. McKee's example is the candlelit dinner where both lovers say "I love you." An actor can rescue it by playing desperation or a setup for a breakup: "When there's a problem, that's when the candles come out." Nonrealism is the exception, since it deliberately reduces subtext. |
| **Monologue fallacy** (8) | A long, unreactive speech to nobody. At 2-3 spoken words per second, a two-minute speech is about 300 words. | Break it into beats of action and reaction, inside the speaker and between the speaker and a silent listener. McKee's examples: in Strindberg's *The Stronger*, the silent Miss Y becomes the star role. In *August: Osage County*, the scenes are built around the listeners' reactions. |
| **Duelogue** (8) | McKee's term for two characters talking "directly, explicitly, and emotionally about their immediate problem." His example is the dungeon scene in *Gladiator* (2000). | Divert it into a **trialogue** by routing the conflict through a third thing. Examples: the canaries in Kennedy's *Legs*, Heisenberg in *Breaking Bad*, Godot. |
| **Repetition** (9) | Accidental echoes of words. More seriously, repeated beats: the same action and reaction, or the same value charge, beat after beat, hidden behind new wording. "Monotony is lifelike... and lifeless." The law of diminishing returns means the third tragic scene in a row gets a laugh. | Make every beat top the one before it. Read the lines aloud. |
| **Misshapen lines** (9) | Blurred meaning (vague nouns and verbs), meaning that lands too early or too late, and mistimed cues. A core word that lands mid-line makes the other actor wait. McKee demonstrates with *Agnes of God*. | Use specific nouns and verbs. End each speech on its core word. |
| **Misshapen scenes** (9) | The turning point comes too soon (then exposition runs downhill), too late (the audience saw it coming), or not at all ("If nothing changes, nothing happens"). | Build beat by beat to a well-timed turning point. |
| **Splintered scenes** (9) | The inner drive and the outer behavior split apart. Four causes: strong motive with bland talk; weak motive with overwrought talk; motive and behavior irrelevant to each other; desires running side by side without conflict. Profanity is often used to hide a non-event. "A silent gangster is a lethal gangster." | Rebuild from the inside out, from desire to action to words. |
| **Paraphrasing trap** (9) | Endless rewording makes lines more on-the-nose. | Fix the event and the character design, not the words. |

## 4. From page to screen: the core translation principles

McKee explains what dialogue is and how it fails. What follows is this file's own conversion of those ideas into staging principles. Each principle names the McKee idea it comes from.

### P1. Film the action, not the words (from dialogue-as-action, Ch. 1-3)
A shot list that follows the words just shows whoever is talking. A shot list that follows the actions shows the doer, the receiver and the change. Before choosing any shot, write the gerund for the line. The gerund, not the sentence, decides the framing. *Warning* wants the receiver's face. *Hiding* wants the speaker's hands. *Punishing* may want distance and stillness.

### P2. The landing face carries the scene (from text/subtext and the action/reaction beat, Ch. 3 and 9)
A beat is half action and half reaction, and the reaction is where the audience learns whether the action worked. On screen, the listener's face is often more informative than the speaker's.

McKee's own dry-cleaner example (Ch. 2) makes the point from the writer's side: when Charlie insults Harry, "the audience's eye glances to Harry to capture his reaction," and the facts slip in while the eye is on the receiver.

Editors have known this for a century:
- The Kuleshov experiments of the 1920s suggested that audiences read emotion into a neutral face from the shot next to it. Hitchcock describes the effect in Truffaut's *Hitchcock/Truffaut* (1966) and demonstrated it on CBC Television's *Telescope* (1964), using his own face. Modern replications are mixed: a 1992 re-creation by Prince and Hensley found no effect, while later studies (Mobbs and colleagues, 2006; Barratt and colleagues, 2016) found a measurable one. Treat it as a real but modest tendency: context shapes how a face is read, but a neutral face cannot carry a turn on editing alone.
- Walter Murch's *In the Blink of an Eye* ranks *emotion* first among his six criteria for a cut, ahead of story and rhythm.
- Ingmar Bergman and Sven Nykvist's *Persona* (1966) plays the same long speech twice, once on the listener's face and once on the speaker's. It is a demonstration that the choice of face is a choice of meaning.

So for every key line, decide the landing face on purpose. It is often not the speaker's.

### P3. The unsaid needs a visible carrier (from the three spheres, Ch. 3; "The camera cannot photograph thought," Ch. 5)
In prose, the narrator can simply tell us what a character did not say. On screen, something visible or audible has to hold it. The usual carriers are:
- a held reaction
- the hands and what they do to a prop
- an object that keeps reappearing
- a distance that opens or closes between bodies
- a sound that swells or drops out
- a frame within a frame

The breakdown must name the carrier. "She is hurt" is not a shot. "Her thumb stops turning the ring" is.

### P4. Activity is chosen to carry or contradict the action (from action versus activity, Ch. 2-3)
Physical activity is not decoration. Choose it so that it either:
- **carries** the action, as when a slammed drawer is the refusal, or
- **contradicts** the words so the gap becomes visible, as when "I'm fine" is said while scrubbing a clean plate.

McKee counts gestures and tasks as physical action, and he says gestures can "substitute" for words. In a key scene, give each character either a task for the hands or a deliberate stillness, and make it change at the turning point (the task stops, starts, or turns into something else; the stillness breaks). Stillness is a valid choice, and often the strongest one for the most powerful character in the room (see P10 and "Silence as threat / power" in section 5).

### P5. Silence and pauses are shots, sounds and cuts (from the pause and the case for silence, Ch. 3 and 5)
A written pause becomes one of four screen choices:
1. a **hold**, so time stretches on one face
2. a **cut**, to the other face, to an insert, or to the next scene
3. a **sound choice**, where room tone rises or a single sound (a clock, a pump, a train) fills the gap
4. a **camera move**, a slow push-in that increases pressure

Pre-turn pauses build pressure. Post-turn pauses let the change sink in. Budget them: McKee's "A pause must be earned" means a breakdown that marks every "(beat)" as a long hold has flattened all of them.

Choices 1, 2 and 4 are picture choices; pick exactly one per pause. Choice 3 (sound) is always also required, because every pause needs a sound plan (R17). This file's default durations, so that an LLM can write numbers into the breakdown:

| Pause size | Screen length | Use for |
|---|---|---|
| Short | under 1 second | an ordinary "(beat)"; usually absorbed into the cut |
| Medium | 1 to 2 seconds | a reaction the audience must see register |
| Long hold | 3 seconds or more | the one or two ranked pauses that carry a turn (R15) |

Which picture choice to use:
- **Hold** when the character in frame is *waiting* or *being waited out* (the pressure comes from time passing).
- **Push-in** when the character in frame is *deciding* (the pressure comes from inside them). Use no more than one push-in per scene, or it stops meaning anything.
- **Cut** when the pause is a *refusal* or an *exit* (the cut itself is the silence), or when the post-turn pause needs to show a new distance between bodies (cut wide).

### P6. Exposition is staged as a weapon, and the camera watches the target (from exposition as ammunition, Ch. 2)
When a fact is used as ammunition, stage three things: who holds the fact, who it hits, and what it costs the one who fires it. The landing face for a fired fact is almost always the target's; McKee's Harry example (Ch. 2) is exactly this. The exception is a confession, where the secret belongs to the speaker and the cost of saying it is the story (R2). The fact-holder often controls the space by standing, holding the prop, or blocking the exit. When a fact is forced (people telling each other what they both know), the breakdown's best tool is to replace it with an image, an insert or a prop, and to flag the line.

### P7. Frame the conflict levels that are in play (from the conflict complex, Ch. 4)
Each of McKee's four levels has a natural home in the frame:
- **Physical** conflict needs the environment and its hazards visible. That means wide shots and inserts of the danger.
- **Social** conflict needs the institution visible: uniforms, architecture, rules posted on walls, witnesses, glass partitions, formal symmetrical staging.
- **Personal** conflict lives in two-shots, singles and the distance between bodies.
- **Private** conflict lives in close-ups, point-of-view shots and subjective sound.

A complex scene keeps several levels in the frame at once. A physical-level scene needs little dialogue, as McKee's quantity rule predicts, and the breakdown should not add any.

### P8. Cut on the core word (from line design and cueing, Ch. 5 and 9)
McKee wants each line to end on its core word because that word cues the other actor's reaction; a core word placed early means "Actor B must swallow her response and wait" (Ch. 9). For the editor, the core word is also the natural moment to cut to the landing face, and a split edit is the editor's rescue for a line the writer shaped the other way:
- A suspense line (core word last) cuts cleanly at its end.
- A cumulative line (core word first) should cut to the listener *early*, letting the rest of the line run over the reaction as a split edit.

Mark the core word in the breakdown.

### P9. Distance and shot size follow value, not volume (from repetitious beats and misshapen scenes, Ch. 9)
If every beat is shot the same way, the film repeats itself visually even when the lines vary. That is McKee's repetitious-beat flaw carried over to the camera. Let shot size, camera height, lens length or the distance between bodies progress toward the turning point and change after it.

Sidney Lumet describes this kind of plan for *12 Angry Men* (1957) in *Making Movies* (1995): lenses grew gradually longer and the camera moved from above eye level (first third) to eye level (second third) to below it (last third), so the room seemed to close in. For the final exterior he switched to a wide lens to let the audience breathe: the change *after* the turn is part of the plan.

### P10. Understate on screen (from film's magnifying camera, Ch. 4; melodrama, Ch. 6)
The camera magnifies, so the screen needs less. When a line is big, the staging should usually be small: stillness, a held frame, no music swell. McKee's "Crucify him" whispered while the king examines his manicure is a staging instruction as much as a writing one. The activity (the manicure) against the action (condemning a man) shows power.

## 6. Decision rules

Each rule has the form "If ... then consider ... because ...". The rules are grouped by the question they answer. The phrase "then consider" is deliberate: these are defaults to start from, not laws.

**How an LLM applies these rules.** Read "consider X" as "do X by default." Depart from the default only for one of the reasons below, and write the reason in the beat's `flags` field.

Order of precedence, highest first:
1. **The script's own directions about what we see** ("Looks at her brother. Not at Jude.", "He does not answer.", "Iona finds his eyes in the mirror.") are binding. They override every rule below.
2. **The flaw rules (R35-R38)**: never rewrite dialogue, never hide a missing turning point.
3. **The turning-point rules** (R7, R13, R14, R30) beat rules about ordinary lines.
4. **The pause budget** (R15) caps every other rule that asks for a hold.
5. All remaining rules.

Tie-breaks for rules that pull in opposite directions:
- **R1 vs R2** (a line aimed at someone that is also a risk for the speaker, such as a confession or a dangerous question): hold on the speaker through the line; cut to the receiver on the core word; hold the receiver through the pause after.
- **R6 vs R7** (a small beat that is also the break): R7 wins; the move from two-shot to singles happens on the turning line.
- **R19 vs R2** (a fired fact that also costs the shooter): land on the target; give the shooter one short reaction after the target's hold.
- **R29 vs R1** (a volley in which each line lands on someone): stay in one angle for the volley; give only the line that carries the change (usually the last) a new, closer shot, on whichever face R1 or R2 selects. Do not cut back and forth to get there.

### 6.1 Whose face? (landing face and reaction shots)

- **R1.** If a line is an action aimed at another character (warning, accusing, begging, revealing), then consider making the *receiver's* face the landing face and hearing the line partly or wholly off-screen, because the beat's result shows in the receiver (Ch. 3, 9).
- **R2.** If the speaker is the one taking the risk (confessing, asking the dangerous question), then consider holding on the *speaker* through the line and the silence after it, because the cost of speaking is the story.
- **R3.** If the audience should share a character's not-knowing, then consider staying on *that* character's face or point of view when the other character withholds, because the camera then withholds too, which creates narrative drive (Ch. 2).
- **R4.** If the audience should know more than a character does (dramatic irony), then consider showing the hidden thing in a shot the other character cannot see, such as a hand behind a back or an object pocketed, because McKee defines suspense as "curiosity charged with empathy" (Ch. 5), and showing the audience the hidden thing turns curiosity into worry on the character's behalf. Hitchcock's bomb-under-the-table example in *Hitchcock/Truffaut* makes the same case for the camera: show the bomb first and a dull conversation becomes suspense; hide it and you get only a moment of surprise.
- **R5.** If a third character is present but silent, then consider giving them at least one reaction shot at the turning point, because silent witnesses carry the social level and often plant their own story.
- **R6.** If two characters of equal weight are in a personal conflict and the beat is small, then consider staying in a two-shot rather than cutting to singles, because splitting a small beat into singles inflates it.
- **R7.** If the relationship breaks at the turning point, then consider moving from two-shots (together) to singles (separated) *at the turn*, not before, because the change in framing *is* the break.

### 6.2 Hands, props and activity

- **R8.** If the script names a task (unwinding wire, eating, wiping, driving), then consider framing it together with the face, or giving it inserts at beat changes, because the activity carries the action (Ch. 2-3).
- **R9.** If a character stops or changes an activity, then consider treating that moment as a reaction shot in its own right, because the hands often react before the face.
- **R10.** If the script gives no task in a talk-heavy scene, then consider proposing one that *contradicts* the words or *carries* the action, marked as "added," because empty hands push actors toward on-the-nose playing.
- **R11.** If an object is passed, grabbed, hidden, destroyed or switched off, then consider marking it as a beat and giving it an insert, because a transfer of an object is a transfer of power.
- **R12.** If an object appears in more than one scene with changing meaning, then consider logging it as a carrier and framing it the same way each time with one change, because repetition with variation lets the audience read development.

### 6.3 Pauses and silence

- **R13.** If a pause comes right before a turning point, then consider a hold (if the character in frame is waiting or being outwaited) or a slow push-in (if the character in frame is deciding), with room tone only, because the pause compresses tension (Ch. 5).
- **R14.** If a pause comes right after a turning point, then consider holding on the receiver, or cutting wide to show the new distance, because the audience needs time to absorb the change (Ch. 5).
- **R15.** If a scene has more than two marked pauses (any "(beat)", "pause", "silence", "a long moment", "She waits", or a stage direction with no line in it), then rank them all and give a long hold (3 seconds or more) only to ranks 1 and 2; make the rest short (under 1 second) or medium (1-2 seconds), or turn them into cuts, because "A pause must be earned" (Ch. 5). Rank by closeness to the turning point first, then by how much the pause changes what the audience knows.
- **R16.** If a character refuses to answer, then consider treating the silence as their line: give it a shot, a duration and a gerund (*refusing*, *punishing*, *protecting*), because silence is an action (Ch. 3).
- **R17.** If the scene's silence would be digital dead air, then consider specifying room tone and one small real sound, because true silence reads as a technical fault and a single sound gives silence a pulse.
- **R18.** If lines could be replaced by a nod, glance or gesture without losing the action, then consider marking them "can play silent" for the director, because "Silence invites the camera in" (Ch. 5). Do not delete the writer's words in the breakdown. Flag them instead.

### 6.4 Exposition

- **R19.** If a fact is fired as ammunition, then consider holding on the target's face through the fact and just after it, because the fact is learned through the emotion it causes (Ch. 2).
- **R20.** If a fact is planted for a later payoff, then consider giving it a clear, not emphatic, shot: one insert or one readable single, held just long enough to read (about 1-2 seconds), with no push-in, no music accent and no second close-up of the same thing, because the audience must be able to remember it without guessing that it matters (Ch. 2 on ranking facts). If McKee's fact ranking marks it as critical, plant it a second time in a later scene rather than lingering longer the first time.
- **R21.** If a fact can be shown by an object, a test or a demonstration, then consider putting the object in frame and letting the line confirm it, because showing beats telling (Ch. 2).
- **R22.** If exposition is forced, then consider playing it off-screen over a more active image, or flagging it, because the screen audience "concentrates through its eyes" (Ch. 7).

### 6.5 Conflict levels and space

- **R23.** If the physical level dominates, then consider minimizing coverage of talk and maximizing shots of geography and hazard, because physical conflict needs little dialogue (Ch. 4).
- **R24.** If the social level is present (an institution, a rule, a witness), then consider putting a visible sign of it between the characters (glass, a desk, a uniform, a posted rule), because it makes the institution a physical obstacle.
- **R25.** If a personal conflict sits inside a physical crisis, then consider one tight two-shot for the personal beat in the middle of wide hazard coverage, because the change of scale tells the audience the story briefly turned inward.
- **R26.** If a character's private conflict peaks, then consider the closest shot of the scene, point-of-view shots, and subjective sound, because the private level is the most inward and the most unsayable.

### 6.6 Cutting and line design

- **R27.** If a line ends on its core word, then consider cutting to the landing face right at that word, because that is where the reaction is triggered (Ch. 9).
- **R28.** If a line front-loads its meaning, then consider cutting to the listener early and letting the line finish as a split edit, because staying on the speaker after the meaning has landed makes the audience wait.
- **R29.** If the exchange is a rapid volley (three or more consecutive lines of five words or fewer), then consider fewer cuts (a two-shot, a deep-staged frame, or a held single with the other voice off-screen), because ping-pong cutting of short lines looks mechanical and hides the turn.
- **R30.** If the turning point is a single line, then consider changing the shot grammar at that line (new angle, new size, camera stops moving or starts), because the audience should *feel* the value change as well as hear it.
- **R30a.** If a line is cut off mid-sentence (the script ends it with a dash, as in "Io. This says-" or "In the car-"), then consider staying on the interrupted speaker's face through the interruption, or cutting to them just after it, because the unfinished half of the line is an unsaid, and the face is where the audience reads it. McKee notes that actors facing badly cued lines "cut off each other's lines, talk over each other" (Ch. 9); a written interruption is the deliberate version and should be timed, not left to chance.

### 6.7 Speeches, narration and adaptation

- **R31.** If a speech runs long, then consider marking each change of tactic as a beat and choosing, beat by beat, speaker or listener, because a speech without reaction is McKee's monologue fallacy (Ch. 8).
- **R32.** If prose narration states what a character thinks but does not say, then consider converting it into (a) a held face, (b) a carrier object, (c) an activity or (d) a staging choice, before considering voice-over, because "The camera cannot photograph thought" and voice-over tends to become "and then... and then..." telling (Ch. 2, 5).
- **R33.** If a prose passage summarizes a conversation (indirect dialogue), then consider picking one line to dramatize and summarizing the rest in images, because summary protects against banality (Ch. 4).
- **R34.** If a novel's best language is in the narration, then consider translating its *images* into production design and composition rather than into lines, because novelists put their finest language in narration, not dialogue (Ch. 5).

### 6.8 When the dialogue itself is flawed

- **R35.** If a line is on-the-nose, then consider (a) flagging it and (b) staging a hidden action beneath it, because a staging subtext can partly rescue it. McKee's actor would play desperation under "I love you" (Ch. 8).
- **R36.** If a scene is melodramatic (big words, small stakes), then consider the stillest staging: a static camera, a shot size one step wider than the scene's other beats, no score, and flag `melodrama`, because inflating it visually multiplies the flaw (Ch. 6).
- **R37.** If the scene has no turning point, then consider flagging it and *not* hiding it with busy coverage, because coverage cannot create an event (Ch. 9).
- **R38.** If you are tempted to rewrite lines in the breakdown, then consider flagging instead, because rephrasing tends to make lines more on-the-nose (the paraphrasing trap, Ch. 9) and the breakdown is not the script.

### 6.9 Coverage grammar: the axis, eyelines and screen direction

McKee does not cover this, but no dialogue breakdown works without it. It matters even more for AI generation, where each shot is generated separately and nothing keeps two clips facing the same way unless the breakdown says so.

- **R39.** If two characters talk, then record for the scene which character is on screen left and which on screen right, and which way each looks (for example, "IONA screen left, looking right; ELI screen right, looking left"), because keeping every camera on one side of the axis of action is what makes separate shots read as one conversation.
- **R40.** If the breakdown uses two singles or two OTS shots as a pair, then consider giving them the same shot size, lens length and camera height, and eyelines just past the lens on opposite sides, because mismatched pairs make one character seem bigger, further away or more important without meaning to. Break the match only on purpose, as a planned progression toward or after the turn (P9).
- **R41.** If the relationship flips at the turning point, then consider crossing the axis *on the turning line* with a visible camera move or a character crossing the room, rather than a cut, because a deliberate crossing reads as a change of sides, while an accidental one reads as an error.
- **R42.** If a third character enters or speaks, then consider re-establishing the geography with one wider shot before returning to singles, because each new pair of speakers creates a new axis.
- **R43.** If a character is seen through glass, a mirror or a screen, then record which side of the glass the camera is on and whether the image is a reflection (mirror-reversed), because reflections flip screen direction and AI tools will not keep that straight on their own.
- **R44.** If a character looks straight into the lens, then treat it as narratized dialogue (direct address, Ch. 1) or a deliberate subjective moment, never as an accident of framing, because a look to camera breaks the fourth wall. Ordinary dialogue singles keep the eyeline just off the lens.

## 7. Procedure: the dialogue pass on one scene

Run this after the scene has been split into beats and its value and turning point have been named. Other files in the library cover scene structure, lens and light in depth. This pass only decides what the *talk* requires of them.

1. **Name each character's scene desire in one line.** What does each character want from this scene? If you cannot say it, stop and flag "splintered scene?" (Ch. 9).
2. **Label every line.** Give it:
   - an **action** (one gerund)
   - the **unsaid** (one short sentence, or "none")
   - the **unsayable** (only if a pattern supports it: the same unnoticed behavior, or the same act against the character's stated aim, appears at least twice in the source, in this scene or others; cite both places; otherwise leave it blank)
   - the **core word**
   - its **function**: exposition, characterization, or action. Most lines are action plus one other.
3. **Mark the facts.** For each piece of exposition, note whether it is fired as ammunition, planted, forced, or shown by an object.
4. **Mark the conflict levels** present in the scene (physical, social, personal, private) and the visible sign of each.
5. **Find the turning point line** and mark the pauses before and after it. Rank all pauses and give long holds to one or two at most.
6. **Set the geography** (R39-R44): who is screen left and screen right, which way each looks, where any glass, mirror or screen sits, and whether the axis is crossed at the turn.
7. **Choose the landing face for each key line** (R1-R7, using the tie-breaks at the top of section 6). A "key line" is any line that carries a turning point, a revealed or fired fact, a refusal, an interruption, or a question left unanswered. Write the reason in five words or fewer.
8. **Assign activity and carriers.** For each character, choose a task for the hands or a deliberate stillness, and say how it changes at the turning point. List every carrier and third thing, and note when each is inserted.
9. **Set cut rules.** For each key line, choose one value: `cut_on_core_word`, `cut_early_split` (split edit), `hold`, or `no_cut_two_shot`.
10. **Set sound for silences.** For each pause, choose room tone, a single sound, or music, and a duration (short, medium or long hold, section 4 P5). Choose music only if it does not state the subtext.
11. **Check progression.** Shot size, distance between bodies or camera height should move toward the turn and change after it. If every beat has the same framing, revise.
12. **Run the flaw screen** (section 3.7 and R35-R38). Flag problems. Do not rewrite dialogue.
13. **Run the checklist** (section 8).

### Output fields (dialogue layer of the breakdown)

These fields can be merged into whatever per-shot format the pipeline uses. Fields marked "added" record choices that go beyond the source text, so a human can accept or reject them.

```yaml
scene_id: 07
scene_desires:
  IONA: "make Eli admit what he did and why he hid it"
  ELI: "be forgiven without having to say he was wrong"
value: "Iona's case against Eli (+ for her at the start, collapses to - at the turn)"  # one reasonable reading
turning_line: "ELI: You."
conflict_levels: [personal, private, social(glass partition)]
third_thing: "security recording on monitor; remote control"
geography: "IONA screen left looking right; ELI screen right looking left; monitor beyond the glass, behind Eli's shoulder; axis not crossed"  # added: the page does not fix positions
beats:
  - beat: 7.4
    line: "IONA: What was it rated for?"
    action: pressing
    unsaid: "She already suspects the answer."
    unsayable: ""
    core_word: "rated for"
    line_design: suspense
    function: [action, exposition]
    landing_face: ELI
    landing_reason: "he must decide to answer"
    activity: "Iona holds the remote, thumb still"
    carrier: "remote (who controls the recording)"
    pause_after: {rank: 2, size: long_hold, seconds: 3, picture: hold, sound: "room tone, monitor hum"}
    cut_rule: hold
    flags: []
    added: []
```

Allowed values, so that every breakdown uses the same words:
- `function`: any of `exposition`, `characterization`, `action` (`action` is almost always present).
- `line_design`: `suspense`, `cumulative`, `balanced`, `parallel`.
- `landing_face`: a character name, `INSERT:<object>`, or `WIDE` (all bodies in frame).
- `cut_rule`: `cut_on_core_word`, `cut_early_split`, `hold`, `no_cut_two_shot`.
- `pause_after.size`: `short` (under 1 s), `medium` (1-2 s), `long_hold` (3 s or more). `pause_after.picture`: `hold`, `push_in`, `cut`, `cut_wide`.
- `flags`: free text, each starting with a label: `on_the_nose`, `melodrama`, `forced_exposition`, `repetitious_beat`, `no_turning_point`, `splintered`, `monologue`, `override:<reason>`.
- `added`: a list of every choice not stated or clearly implied by the source.

## 8. Checklist (run against every dialogue scene)

Answer yes or no. A "no" means revise or flag.

1. Does every line in the scene have an action gerund, and are the gerunds different from each other where the beats are different?
2. Does each character have a stated scene desire?
3. Is the turning point line identified, and does the value change charge there?
4. Is there a chosen landing face, with a reason, for every line that carries a turn, a reveal or a refusal?
5. At least once in the scene, is the landing face *not* the speaker? (If never, the plan is probably following the words.)
6. Is every important unsaid assigned a visible or audible carrier (face hold, hands, object, distance, sound, frame within a frame)?
7. Does each character have an activity or a chosen stillness, and is its change at the turning point written down?
8. Is every third thing kept in frame or inserted at the turns?
9. Are pauses ranked, with long holds given to at most one or two?
10. Is each silence given a sound (room tone or a single sound), not left as dead air?
11. Are planted facts given a readable shot, and fired facts held on the target?
12. Is forced exposition flagged, or moved to an image?
13. Is each conflict level in the scene visibly present in at least one frame?
14. Does framing progress (size, distance, height, lens) toward the turn and change after it?
15. Are short volleys covered without ping-pong cutting?
16. Are long speeches broken into beats with listener coverage, or staged with the listener in frame?
17. Is there any music or sound that states the subtext outright? (It should be "no".)
18. Are metaphors in the lines left un-illustrated, unless a real object in the scene already matches them?
19. Are all flaws (on-the-nose, melodrama, repetition, no turn) flagged rather than rewritten?
20. Are all choices beyond the source text marked "added"?
21. Is the geography recorded (who is screen left and right, which way each looks), and does every paired single or OTS keep it, except for a crossing planned at the turn?
22. Does every script direction about what we see ("Looks at her brother. Not at Jude.") appear in the plan unchanged?
23. Is every interrupted line (ending in a dash) given a landing face?

## 9. Common mistakes in dialogue breakdowns, and how to spot them

| Mistake | How to spot it | Fix |
|---|---|---|
| **Following the speaker** | The shot list alternates A, B, A, B in step with the lines. | Choose a landing face per line (R1-R7). Allow off-screen lines. |
| **Illustrating the words** | A line mentions an object and the plan cuts to that object every time. | Insert an object only when it *changes* or is handled at a beat (R11). |
| **Emotion labels in place of actions** | Notes say "she is sad," "he is angry." | Replace them with a gerund and a visible behavior: "*withholding*: looks at the flask, not at her." Actor-directing books such as Judith Weston's *Directing Actors* (1996) make the same case for playable verbs over result words. |
| **Adding the unsaid as speech** | New lines or voice-over explain what a character feels. | Delete them. Assign a carrier instead (P3). |
| **Scoring the subtext** | A music cue "tells" the audience the hidden feeling. | Use room tone or a single diegetic sound (sound that exists inside the scene's world). Save score for transitions or for counterpoint. |
| **Every beat a hold** | Five or more "long hold" marks in one scene. | Rank the pauses. Earn the one that matters (R15). |
| **Flat progression** | The same shot size and angle from first line to last. | Plan a progression toward the turn (P9). |
| **Over-coverage of small beats** | A two-line exchange gets four singles and two inserts. | Use a two-shot or a held single (R6, R29). |
| **Losing the listener in a speech** | A long speech is covered only on the speaker. | Cut to the listener at tactic changes (R31). |
| **Losing the third thing** | The object two characters fight through is not in frame at the turn. | Keep it in frame or insert it at each turn (R11, R12). |
| **Literal metaphors** | A line's figure of speech becomes a shot ("holding a door open with his back" becomes a man at a door). | Play it on the face (see the translation table). |
| **Hiding a non-event** | Busy camera moves and many angles in a scene where nothing changes. | Flag "no turning point" (R37). |
| **Rewriting the dialogue** | The breakdown's quoted lines differ from the script. | Quote the source exactly. Put suggestions in flags. |
| **Voice-over dumping in prose adaptation** | Narration becomes voice-over wholesale. | Convert through face, object, activity or staging first (R32). |

## 10. Worked examples

All screenplay quotes are exact, from *The Catch* (workshop revision, 25 September 2026). The prose quotes are exact, from *The Long Places*. Choices marked **(added)** go beyond what the page states.

### Example 1. The loading tunnel: exposition as ammunition, and the hands as reaction (*The Catch*, opening)

**The page.**

> JUDE: Goods only. No persons.
> IONA (O.S.): They all say that.
> ...She puts a finger into one of the holes. Feels the thread. Still sharp.
> She stays on her knees. One breath.
> Above her, Jude unwinds the wire from the gate.
> IONA: The safety brakes are gone.
> He stops unwinding.
> JUDE: Stairs? / IONA: Guard on each door. / He looks up the ladder. / JUDE: Can he climb? / IONA: Not when I last saw him.
> ...IONA: Ropes are sound. Take it gentle. Stop it hard and there's nothing under it to catch us.
> JUDE: I know how a lift works, Io. / IONA: I know you know.
> Jude finishes taking the wire off. Hooks the tag back on the gate.

**Reading the actions.**

| Line | Action |
|---|---|
| "They all say that." | *dismissing* the rule |
| "The safety brakes are gone." | *warning*, and *testing* Jude's nerve |
| "Stairs?" and "Can he climb?" | *searching for another way* |
| "Not when I last saw him." | *closing the last exit* |
| "I know how a lift works, Io." | *bristling at being managed* |
| "I know you know." | *soothing while keeping command* |

- **Exposition.** Four facts arrive, and each is ammunition in a live decision (go or don't go): no brakes, guarded stairs, the man they have come for may not be able to climb, a hard stop kills. Nobody explains anything. (The page does not name "him" here; the audience learns it is her brother Eli only on the treatment floor, which is itself narrative drive.)
- **The plant.** "Stop it hard and there's nothing under it to catch us" is planted for the moment Iona hits STOP.
- **The unsaid.** Under "Not when I last saw him" is fear for her brother, and the time since she saw him.
- **Conflict levels.** All four are present:
  - physical: the empty brackets
  - social: the tag and the guards
  - personal: a couple bickering under pressure (the paired wedding rings in the last scene indicate they are married)
  - private: Iona's "One breath"

**Screen choices.**

1. **The tag as carrier.** Open on an insert of the red tag turned to the torch, with Jude reading it aloud. Log the tag as a carrier. It is the rule the story breaks, and it returns: "Its red tag whips against the upside-down gate." Frame it the same way both times.
2. **The discovery.** Insert Iona's fingertip in the bright bolt hole. The unsaid "someone removed these recently" is carried by "Still sharp," and no one says it (P3, R21).
3. **One frame for the whole beat.** Stage "One breath" and "The safety brakes are gone" in a single deep frame: Iona low in the foreground in profile, Jude's hands on the wire at the top of the frame. Hold through the line. The landing is "He stops unwinding," and it happens *in the same shot*. No cut is needed, because the hands are the reaction shot (R9). This is the scene's pre-turn pause, so give it room tone (dripping, a far motor), not music (R13).
4. **The volley.** "Stairs?" to "Can he climb?" plays in one angle with the height difference intact: she kneels, he stands (R29). Jude's "looks up the ladder" becomes a tilt up the shaft (the camera pivots upward), which plants the ladder and the yellow band for later.
   - Then change the shot once, for the last line of the volley: "Not when I last saw him" lands on Iona's face in a closer shot, because the line costs her (R2, and the R29 vs R1 tie-break). This is the only cut in the volley.
   - When she rises, the frame levels. The power move is her standing up, not a line.
   - Geography (R39): keep Jude on the same side of frame in every set-up of this scene, so the height relation reads as one space.
5. **The personal beat.** "I know how a lift works, Io" / "I know you know" gets one tight two-shot at equal height, not two singles (R6, R25). It is a small marital beat inside a physical crisis, and splitting it would inflate it.
6. **Activity out.** Jude "Hooks the tag back on the gate." Stage it as a deliberate, unhurried insert. On the page its action is open: *covering their tracks*, or *committing* to the ride. Frame it clearly and do not resolve it. The breakdown should not decide more than the page does.

### Example 2. The car: silence as the answer, and a question that returns three times (*The Catch*)

**The page.**

> IONA: What did that thing do?
> ELI: Saye. The doctor I wrote to. I know where she lives.
> ...Eli watches the backwards city go by. He has not said one word about it. He looks at it the way you look at a result you expected.
> ...A red light. Iona finds his eyes in the mirror.
> IONA: Eli. Are we going to be all right?
> He looks down at the flask in his hand for a long time.
> ELI: Drive.

**Reading the actions.**
- Eli's first reply is *deflecting*: it answers a different question.
- "He looks at it the way you look at a result you expected" is prose-style direction. It states an unsaid (he knew this would happen) that the camera cannot photograph as written.
- Iona's question is the most on-the-nose line in the scene, and it works because she is a character *choosing* to be direct. Her action is *demanding the truth*.
- Eli's answer is silence, and then "Drive." That is *refusing*, and also *protecting* himself and perhaps her. By McKee's Chapter Three, the silence is the action, and "Drive." only puts a lid on it.

**Screen choices.**

1. **The unsaid expected result.** Carry it with a *lack* of reaction. Hold on Eli in profile against the passing mirrored signs, still, eyes moving calmly with the traffic. Intercut Iona's hands white on the wheel as "her skinned palm opens." The contrast between her hands and his stillness says it (P3).
2. **The red light is the clock.** The pause lasts as long as the red light. The audience knows a light must change, and that tightens the pause.
3. **The mirror as frame within a frame.** The landing face for Iona's question is Eli, seen *in the rear-view mirror* from her point of view. When he "looks down at the flask," his eyes leave the mirror's frame. The withdrawal becomes a visible exit, with no cut (R3, R16). The flask stays below the mirror, out of her view. The audience learns that there *is* a secret, not what it is, and that is narrative drive (Ch. 2).
4. **"Drive."** Cut on the word to the car pulling away, because the core word is also the scene's last action (R27). Sound: engine and indicator only. No score.
5. **The rhyme.** The car question comes back three times, and each time the value is different:
   - In the recording scene, Iona names it as the grievance: "I asked you in the car. I could hardly find the gearstick. You let me drive like that." And then: "Then in the kitchen. Don't open the flask. You could say that." The second line is the sharpest statement of the unsaid in the film: Eli could speak when it protected the flask, not when she asked. Land it on Eli (R19), because the fact is being fired at him.
   - On the ship, Eli asks: "Are we going to be all right?" / IONA: "I don't know." The roles are reversed, and she gives him the honest answer he refused her.
   - In quarantine: ELI: "In the car-" / IONA: "Yes." The line is cut off (R30a). Both the apology and its acceptance are unsaid.

   Stage the car, the ship and the quarantine versions through a frame within a frame: the mirror, then the glass walls of the ship's rooms, then the quarantine glass. Change one thing each time: who is framed, and whose eyes stay in the frame **(added)**. This is repetition *by design*, not McKee's repetitious-beat flaw, because the value charge changes each time (Ch. 9).

### Example 3. The recording: a trialogue, a fired fact, and the pauses around a turning point (*The Catch*, quarantine)

**The page (abridged, with exact lines).**

> Iona pauses the recording with the remote. Looks at her brother. Not at Jude.
> IONA: You did that. / ELI: Yes.
> IONA: You could have moved us out of the shaft. / ELI: We would still have been falling.
> Saye draws one finger straight down the screen. Then sideways, into the concrete of the wall.
> IONA: What was it rated for?
> He does not want to answer. She waits. She can always outwait him.
> ELI: One body. / IONA: One. / ELI: You.
> Silence.
> ...ELI: Then it runs out partway. And partway isn't a place.
> SAYE: (quietly) No. It is not.
> Iona glances at her. Saye is looking at nothing.
> ...She opens her mouth. Nothing in it.
> She looks down at her palm, where the sill took the skin off.
> He watches her look at it.
> ...Jude takes the remote and switches it off.

**Reading the actions.**
- **The third thing.** The recording, and the remote that controls it. Iona and Eli fight *through* the footage (Ch. 8).
- **The remote is power over time:**
  - Iona pauses it (*seizing control*).
  - Later she "Lets the recording run" (*releasing*).
  - Jude switches it off (*ending it, protecting both*).
- **The fired fact.** "One body... You." is exposition as ammunition, fired by Eli in self-defense. One reasonable reading, supported by his next lines ("Us, I guessed. One turn. Nearly the whole charge." and "You'd have come up out of that shaft on your own, Io. With me and Jude at the bottom of it."): the device was rated to save one person, and that person was Iona; he gambled it on all three. The fact turns Iona's accusation back on her. The breakdown should stage the fact landing, not explain it.
- **The pauses.** "She waits" is the pre-turn pause, and her action is *pressing*. "Silence." is the post-turn pause.
- **The unsaid at the edge of words.** "She opens her mouth. Nothing in it." answers "Tell me that's what you'd have wanted." Whether she is withholding (unsaid) or has no words for it (unsayable), the page gives it to her body, not her voice. By this file's own rule (section 7, step 2), record it as *unsaid* here; it becomes a candidate for the unsayable only if the same wordless answer recurs elsewhere.
- **A plant.** Saye's "No. It is not." carries her own unsaid, Nell, which pays off in the next scenes.

**Screen choices.**

1. **Establish the trialogue.** The page puts the monitor on Saye's side, "turned to face the glass." Set up that geography: the paused cage image glowing beyond the glass, facing the three of them. The recording sits on the institution's side, which adds the social level to the fight. Keep the monitor in the background of most set-ups (R11-R12). Insert the remote on the pause and on the switch-off.
2. **The accusation.** "Looks at her brother. Not at Jude." The shot must show the choice of whom to look at: Iona in the foreground turning *past* Jude. Jude is soft in the frame, then becomes the witness at the end (R5).
3. **Saye's gesture.** Saye's finger drawing straight down the screen, then sideways "into the concrete of the wall," answers Iona's "You could have moved us out of the shaft" without a word: the cage was falling, and a sideways move would have ended inside solid wall. It is an exposition gesture standing in for a line. Give it a clean insert that includes the edge of the screen and the wall, so the sideways stroke visibly leaves the picture. It is shown, not told (R21).
4. **The pre-turn pause.** "What was it rated for?" / "She waits." Landing face: Eli, in an OTS from behind Iona's shoulder. Hold with no cut, room tone plus the monitor hum (R13). She "can always outwait him," so the shot must outlast comfort.
5. **The turn.** "One body." / "One." / "You." Stay on *Iona*. Hear "One body" and "You" from Eli off-screen, because the turning point happens in her face (R1, R29). Do not ping-pong three one-word lines. Mark "You." by changing the shot on her face (a cut in to a tighter size, or the camera stopping), not by cutting to Eli (R30).
6. **The post-turn pause.** "Silence." Cut wide once, all three of them plus the monitor, to show the new distance. Then hold (R14).
7. **Saye's plant.** "No. It is not." gets one short reaction shot of Saye through the glass, "looking at nothing." It must be readable, not lingered on, because it is a plant for Nell (R20). The glass keeps the social level (the institution) between them (R24).
8. **The answer she cannot give.** "She opens her mouth. Nothing in it." / "She looks down at her palm" / "He watches her look at it." Stage it as one shot with a focus pull: her palm in the lower foreground (the carrier, the wound from catching the sill that saved all three), then rack focus to Eli watching her. (The page does not say where he sits. Keep him on Iona's side of the glass unless the scene plan says otherwise.) One frame holds three layers: the body's memory, her silence, his seeing it.
9. **The ending.** "Jude takes the remote and switches it off." Show Jude's hand entering frame, then the monitor going black. **(added)** In the black screen, the three faint reflections. That rhymes with the story's mirror motif. Mark it as an option.

### Example 4. The mint: exposition by test instead of explanation (*The Catch*, kitchen)

**The page.**

> SAYE: Chew that. / Iona chews it. / Her face changes.
> SAYE: What does it taste of? / IONA: (not steady) Not mint.
> SAYE: Nothing has happened to the mint. Nothing has happened to the street signs either.

**Reading.** The scene's key fact is that *Iona* has been reversed, not the world. It could have been a speech. Instead Saye stages an experiment, which makes the mint a third thing and a carrier, and lets the line confirm what the audience has already felt (R21).

The earlier mirroring beat does the same thing through blocking: "They stand facing each other across the table like a woman and her reflection, each with the wrong hand in the air." The composition *is* the exposition.

**Screen choices.**
- For the hands, use a symmetrical two-shot across the table, square to both women, so the frame itself reads as a mirror.
- For the mint, insert the leaf being torn and handed over.
- The scene has a second test done by activity alone: "Across the room Eli twists the cap of a water bottle. It will not give. He stops. Twists it the other way. It comes off." His hands discover the reversal before anyone names it (P4, R9). Then: "Saye is watching him. He sees her watching." Stage the cap and Saye's watching in one deep-staged frame (Eli's hands near the camera, Saye beyond), so the discovery and its witness land together without a cut.
- Landing face: Iona chewing. Hold through "Her face changes." Cut on "Not mint." to Saye.
- Saye delivers "Nothing has happened to the mint..." plainly, framed with the street-dark window behind her. The world is unchanged, and she is the social level (the doctor, soon the institution).
- No music. The only sounds are chewing and room tone.

### Example 5. The Register and the bread oven: converting prose's unsaid into carriers (*The Long Places*)

**The page (Chapter IV, "The Register").** Nilay reads the Trust's volume, where every year says *Nothing to record*, and finds one margin: "*4–5.ix. Kept the hours. A.H.*"

> She asked whether he had kept the hours at her site, and he said, "Twice," and she asked when, and he said, "Before your birth. And once since." The page lay open between them and had already said when. "I filed my line," he said, and put the volume back with its spine even with its brothers, and the door of that subject closed as softly as it had opened...

And later:

> He wiped the desk where nothing had stood. ... She put the leaves back in their sleeve because her hands needed an instruction, and did not ask the question that was in her mouth, because a question is a lamp you hold up on somebody, and she did not yet want to see his face by it.

**Reading.** The narration states the unsaid three times:
- "had already said when": the date is her missing brother's.
- "the door of that subject closed": Halden is *closing* the subject.
- "did not ask the question": Nilay is *withholding*, out of fear of the answer.

On screen none of that narration exists (R32). The dialogue alone ("Twice." / "Before your birth. And once since." / "I filed my line.") is polite and nearly empty. Halden speaks *under* the facts, which makes this an understated revelation.

**Screen choices.**
1. **The page as third thing.** Frame the open volume flat on the desk *between* them. Insert the margin note so the date is readable, because the page "had already said when." The landing face for "And once since" is not Halden but Nilay looking *down* at the page. The fact lands through the prop (R11, R19).
2. **Halden's activity.** Two actions, carried by activity (P4):
   - Putting the volume back "with its spine even with its brothers" is *ending the subject*. Hold on the shelf until the spine is flush.
   - Wiping "the desk where nothing had stood" is *erasing* a mark that isn't there. Insert the cloth on the clean wood.
   - The same chapter has already shown this gesture once: he "wiped the desk where the teapot had stood, because the water had marked it, thirty years ago." Two occurrences make a pattern, so under section 7, step 2, this habit qualifies for the `unsayable` field: a man who prevents marks from ever being made, the Trust's *Nothing to record* done with a cloth. Frame both wipes identically (same insert size, same side of frame), so the second reads as a repeat (R12). Never explain it.
3. **Nilay's unsaid.** Her hands putting "the leaves back in their sleeve" is the carrier. Close on her hands, then her face with the question visible and unasked. Hold, then cut away before she speaks. The cut is her silence (R16). Do not use voice-over for "a question is a lamp..." In this chapter the figure belongs to the narration. The book uses it twice more: in the keeper's letter that opens Chapter II ("A question is a lamp you hold up on somebody, and the young cannot stand the light of it") and spoken aloud by Emre, her lost brother, in Chapter XIV ("asking is a lamp you hold up on somebody"). An adaptation should save the words for Chapter XIV, where a character says them as dialogue, and let Chapter IV play silent. Log "the question as a lamp" as a cross-scene motif; the story's real lamps are its natural carrier.
4. **"He would be forty."** From Chapter XIV: "Her mother said it to the bread oven, not to her." Stage it with the mother's back to Nilay, framed facing the oven, the line spoken *to the oven*: a third thing. Nilay is in the background, softer. "Then she shut the door of the sentence" can be echoed only because a real oven door exists in the scene: **(added)** the mother closes the oven door on the last word, and we cut to them eating. This is the one case in these examples where a figure of speech is echoed in the image, and it is allowed only because the object is physically present. It is not a license to illustrate every metaphor.

## 11. Handing the dialogue layer to later stages

These notes cover only what the dialogue layer must tell each optional downstream stage.

**Storyboards (optional).**
- Draw the landing face, not the speaker, for each key line.
- Label each panel with the line's action gerund and its core word.
- Draw carriers and third things so they are recognizable across panels: the same object, the same side of frame.
- Mark pauses with a duration (for example, "HOLD 3 s") and silences with "ROOM TONE."
- Keep each character on the same side of the panel across a conversation, and draw an arrow for each eyeline, so the axis (R39) is visible before anything is generated.
- A panel with no dialogue that shows a hand, an object or a face is often the most important panel in a dialogue scene.

**3D previs (optional, for example in Blender).**
- Model each carrier and third thing as a named object, so it can be tracked across shots.
- Block the distance between characters per beat, because that distance is the visible form of the personal conflict.
- Set camera height to match the power relation. In Example 1, for instance, the camera starts low with the kneeling Iona and levels when she stands.
- Time holds against the pause ranking. Previs is where an unearned hold shows up as dead time.

**AI video generation (optional).**

Verified facts. The following were checked on 2026-09-27 against Google's "Ultimate prompting guide for Veo 3.1" (Google Cloud Blog, published 16 October 2025), https://cloud.google.com/blog/products/ai-machine-learning/ultimate-prompting-guide-for-veo-3-1:
- The guide says to "use quotation marks for specific speech."
- It describes separate sound effects and ambient-noise instructions.
- It lists clip lengths of 4, 6 or 8 seconds.
- It offers "timestamp prompting" for timed multi-shot sequences in one generation.

Also checked on 2026-09-27 against Google's Gemini API documentation for Veo 3.1 (https://ai.google.dev/gemini-api/docs/veo, page dated January 2026 for Veo 3.1 and Veo 3.1 Fast):
- It repeats the advice to "use quotes for specific speech," and gives each quoted line a described speaker ("'This must be the key,' he murmured").
- Durations are 4, 6 or 8 seconds; 8 seconds is required when using reference images or extensions.
- Up to three reference images "of a single person, character, or product" can guide appearance.
- A generated video can be extended in 7-second steps.

Google's separate Vertex AI "Video generation prompt guide" was also looked up on 2026-09-27, but the page did not render for checking, so nothing here relies on it. Model features change quickly, so re-check the current guide for the model in use.

Practical consequences. These are this file's recommendations, not vendor claims:
- **Budget words per clip.** McKee puts the average speaking rate at 2-3 words per second (Ch. 8). An 8-second clip therefore holds at most about 16-24 spoken words, and fewer if the beat contains a pause. McKee's economy rule becomes a production constraint: one beat per clip is a safe default.
- **Generate reaction shots as separate clips.** State explicitly that the character does not speak ("she listens; no dialogue"). Reaction shots are where the story's meaning lands, so treat them as first-class shots, not filler.
- **Describe subtext as visible behavior.** A model renders what is described. Write "he looks down at the flask and does not answer," not "he is secretly guilty." Emotion labels invite generic acting. Physical specifics (hands, eyes, distance, an object) give the result something to show.
- **Write the silence into the prompt.** For held pauses, put room tone and a single sound in the audio instructions, and state the duration of stillness. Otherwise a model may fill the gap with speech or music.
- **Keep carriers consistent.** Describe the same prop with the same words in every clip, such as "a small steel flask, the kind that keeps coffee hot." A carrier only works if the audience recognizes it.
- **Name the speaker of every quoted line.** Tie each line to a described character in the same sentence ("the kneeling woman says, '...'"), as Google's own examples do. With two people in frame and unattributed quotes, a model may give the line to the wrong mouth.
- **Prefer off-screen lines on the landing face.** When the landing face is the listener (R1), the speaker's line can be generated or recorded as audio only and laid under the listener's clip as a split edit in the edit. This avoids lip-sync on the speaker entirely, which is one of the least reliable things for current models to get right, and it is also the better film grammar.
- **Carry the geography into every prompt.** Put the scene's screen-left / screen-right placement and each eyeline into every clip's prompt ("she is on the left of frame, looking right, just past the camera"), because each clip is generated without knowledge of the others (R39-R40). Check the result: a model will sometimes mirror a composition, which silently crosses the axis.
- **Say where no one should look.** For ordinary dialogue singles, state that the character does not look into the camera; a look to lens reads as direct address (R44).

## 12. Open questions for the pipeline

- How should the breakdown handle scenes where the writer's stage directions already dictate the landing face ("Looks at her brother. Not at Jude.")? This file now treats them as binding (precedence rule 1 in section 6). A pipeline setting could make them advisory for directors who want freedom.
- The unsayable is inferred, and inference can overreach. This file sets the bar at two occurrences anywhere in the source (section 7, step 2). A stricter pipeline could require two *scenes*.
- The pause durations (short / medium / long hold) and the 40-word speech threshold are this file's working defaults, not McKee's. They should be tuned after the first test runs.
- McKee's Part Four (beats, the five steps of behavior, and the case studies) falls outside this file. A later file should cover beat analysis in more detail, and the procedure in section 7 assumes it.
