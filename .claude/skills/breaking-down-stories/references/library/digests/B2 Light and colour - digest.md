# Digest B2: Light and color as meaning

Source: `research/B2_light_and_color.md` (861 lines). Brackets: P# = core principle (§1), R# = decision rule (§7), § = section, Ex# = worked example (§10). "Consider" rules apply by default unless the script or a higher-priority rule overrides; name the rule applied or overridden in the shot's WHY line [§7].

## 1. Scope

1. Turns story meaning (threat, secrecy, grief, a story value changing) into light and color per location, sequence, scene and shot: translation table, 30 rules, checklist, mistakes.
2. Supplies three templates (location lighting plan, one-row-per-sequence text color script, per-shot LIGHT/COLOR/WHY/PROMPT spec) and AI phrasing plus cross-shot light consistency.
3. Runs after the scene breakdown (beats, story value changes known), before shot prompts. Worked for *The Catch*; one *The Long Places* example.

**Terms** [§0.1]: *source* (where light seems to come from in the story world); *key* / *fill* (main light / weaker shadow-side light); *practical* (working light visible in frame); *motivated light* (film light seeming to come from a story source); *hard / soft* (source looks small / large from the subject); *falloff* (inverse-square: twice as far, a quarter of the light); *temperature* (kelvin: low = orange "warm", high = blue "cool", relative to the white balance); *value* (lightness); *accent* (small area sharply unlike the palette); *story value* (McKee; always written in full, apart from color value); *light cue* (a story-caused light change); *frame-left/right* (as the audience sees). *The Catch*'s "torch" = flashlight.

## 2. Rules

**Priority on conflict** [§7], highest first: **L1** light and color the script states (R3, §5.1): never drop or contradict. **L2** readability of the beat (R5, R23, R24, R27). **L3** the film's motif code (§8.4). **L4** the color script's curve (§8.5). **L5** location continuity (plan, R20-22). **L6** translation-table defaults (§6). Example: R10's cue at the turn loses to "Nothing has happened to the mint" (L1).

**Principles**
1. [P1] If a frame is beautiful but sends the eye wrong, then it fails, because light serves attention, then emotion, then beauty.
2. [P2, R4] If a light has no story source, then give it one or confine it to a moment outside ordinary time (turn, void, dream), because sourceless light reads as unreal.
3. [P3, P11] If planning light, then plan across the film and per location, varying per beat, because meaning comes from change, not absolute levels.
4. [P5] If light must be harder, then make the source look smaller (larger or closer = softer), because hardness is apparent size, not brightness (hard: exposed, dangerous; soft: gentle, intimate).
5. [P6, §2.2] If choosing direction, then: front reveals or interrogates; side (~90°) divides; three-quarter (30-60°) is the default; back separates, idealizes or hides; top loses the eyes (institution); under only with a low source (fire, screen, torch), because direction carries attitude.
6. [P7] If designing a scene, then design what stays dark, because suspense and secrecy live there.
7. [P10] If a scene has several light ideas, then keep one, because motifs work by rarity.
8. [P12] If writing for AI, then describe the visible result, not the rig, because models follow results.

**Sources and faces**
9. [R1] If night interior, then consider one practical as key, all else falling off, because one source reads as real.
10. [R2] If a character carries the light, then consider it the key for all they look at, because attention follows their point of view.
11. [R3] If the text mentions a source, then it must appear or be motivated, because script light is story.
12. [R5, P8] If a thought must be read, then keep an eye light and fill that shows the eyes (drop it only to withhold), because eyes carry a close-up.
13. [R6, R7] If a character hides something from another character only, then hide a body part or object, not the face (Eli's hand); if also from the audience, consider top or side light losing the eyes, because we must see the hiding, and withheld eyes withhold interiority.
14. [R8] If two characters mirror each other, then consider symmetric light from one source between them, because it shows the mirror.
15. [§2.3] If setting contrast, then use key-to-fill bands: low ~2:1 (1 stop: safety, baseline); medium ~4:1 (most drama); high ~8:1 (secrecy, night interiors); extreme 16:1+ (shadow side black: noir, revelation), because the ratio sets openness vs hiding; high-key is not automatically happy, nor low-key sad.

**Structure**
16. [R9, §4.4] If a sequence builds to a climax, then keep it at least 1 saturation point (1-5) or 1 contrast band below the climax in the component the climax peaks in; set the climax first; if the opening maxes one component, name another for the climax, because intensity needs room (Block).
17. [R10] If a scene turns and a story source can plausibly change then (door, screen, lamp set down, machine, signal), then consider one cue at the turn; if none can, or the world has not changed, keep light fixed, because the cue marks the story value change without dialogue.
18. [R11, R12] If a revelation is large, then consider the flattest light available; if a scene is already loud, simplify to one rhythm or source, because ordinary light makes truth undeniable and chaos on chaos loses clarity.
19. [R13, §3] If the story has two worlds, then consider a lighting logic for each, meeting at boundaries, because crossings are felt (without a story need it is a filter).
20. [§8.3] If three sequences in a row share value, saturation and temperature, then change one unless the row says why, because monotony flattens the curve.

**Color**
21. [§4.2] If designing color, then value first, saturation second, hue last, because value and saturation carry most feeling.
22. [R14] If a color is a motif, then keep the palette around it low in saturation, because accents need affinity.
23. [R15, §4.7] If a motif must read under a location's light, then check surface times light and self-light the object or change the light, because surfaces reflect only colors in the light (blue under sodium goes near black).
24. [R16, §4.8] If tempted by a warm/cool split, then name the story opposition and which side is which, because otherwise it is the teal-and-orange default.
25. [R17, §4.6] If a meaning comes from an associations book (Bellantoni: hypotheses), then write it in the motif table and teach it at a first appearance that makes it obvious, or drop it, because films teach their own code (*Sixth Sense* red).
26. [R18] If a motif lands on a turning point, then consider inverting it once, because one inversion beats repetition.
27. [R19] If the setting is real, then check signal colors (British emergency lights blue; streetlights by city and decade), because wrong local color breaks belief.
28. [§4.1] If writing a location plan, then name the neutral-white source and call others warmer or cooler, because warm and cool are relative; real green or magenta tints may stay (Müller).
29. [§4.7] If a background matches a principal's skin, then darken or cool it; if a costume is white or black, describe texture and seams (not the figure); keep a motif hue out of dressing and extras where it means nothing; repeat an arc costume color verbatim in every prompt, because faces lead and models drift color.
30. [§5.2] If adding haze, then only where the place has dust, smoke or damp; if a night exterior, choose the streetlight color once and keep it, because god rays everywhere are cliché and drifting local light breaks the place.

**Continuity**
31. [R20] If a scene has several shots, then fix the key side to the set ("window frame-left in the wide"), because flips read as errors.
32. [R21] If the story reverses the world (mirror turn), then consider one lawful flip of the protagonist's close-up key side (frame-left sequences 1-4, frame-right from the BLACK in 4), written in the color script; if the pipeline cannot hold key side, skip it, because an inconsistent flip is worse than none.
33. [R22] If time passes in a location, then step the light and assign each shot a step, because drift reads as error.

**Darkness, materials, machines**
34. [R23] If very dark, then keep one readable element per shot (rim, eye light, lit hand), because comprehension comes first.
35. [R24] If dark skin appears in low light, then expose and fill for it (soft bounce, eye light, not more front light), name skin tone and its light in prompts, and reject frames where it goes grey, ashy or lost while lighter skin looks right, because defaults expose for pale skin.
36. [R25, R25a] If an object is matte black, then rim it against something lighter; if clear, light it from behind or the side (a helmet lamp skimming it), because black shows only edges and front-lit glass only reflections.
37. [R26] If light comes from a machine, then dip it once exactly when the script says power falters and let it die with the machine, never flicker otherwise, because machine-tied light is motivated.
38. [R27] If a character wears a visor, then in every close-up light the face from inside the helmet (lamp or display glow) and decide face or world in the visor, because a mirrored visor loses the face.
39. [R28] If one costume or object is far brighter than the rest, then expose for the face and keep its detail, because otherwise it glows featureless.
40. [R29] If a screen lights a face, then match its color to the picture and change with it, because otherwise it is generic "blue glow".

**Translation defaults** [§6] (L6; propose, then check against the film's own system): safety/home → soft warm practicals, medium-low contrast, eye light on all, warm analogous palette. Threat hidden → low-key, strong falloff, backlight without key; desaturated cool. Threat revealed → an exposing cue (torch finds it) and a sudden accent (not lightning). Secret → top or side light, eyes or hidden hand dark, muted; the hiding stays readable. Revelation → flat, even, top-down; neutral, low saturation. Intimacy → close soft source two faces share. Isolation → pools separated by dark, character outside the pool; cool, desaturated, one unreachable warm accent (not a sad blue wash). Institutional control → flat top fluorescents, no shadows; white, grey, pale green (no flicker). Uncanny → light subtly wrong for its source; a familiar color that no longer means what it did (not green tint). Moral choice → two differently colored sources on one face. Power → figure higher, back- or top-lit. Being observed → lit by others' screens. Grief → soft, low contrast, a light going out; one remembered color. Hope → a source appears or warms; saturation up a step (not sunrise). Other world → an unfamiliar source, a hue not yet used (not magic blue). Care → the carer is or holds the source (no halo). Sacrifice → an accent removed, a light goes out. Relief → contrast and saturation drop (must not look like the opening). Peace with an open question → calm low light, one cool pale accent keeping the unresolved thing readable (not cosy gold). Unchanged world, changed person → keep light and palette exactly. Story value + to − → contrast up, source narrows, warm to cool, green to red; − to + → the reverse, eye light returns (never synced to the line, never mid-shot without a source).

## 4. Procedures

**P1. Order of work** [§0]: (1) inventory the text's light and color words; (2) one lighting plan per location; (3) color script, one row per sequence, before any shot; (4) per-shot LIGHT and COLOR, recording only differences from the plan ("as plan" otherwise); (5) run §11 and §12; (6) translate to model phrases (§13). If output looks generic, run §12 on it.

**P2. Inventory** [§5.1]: copy verbatim, with scene number, every line naming a light source, color, brightness word (bright, dim, pale, glare, dark, black) or light change. An object's color holds under every light. A darkness line ("BLACK") means something stays dark. In prose, literal light goes to the plan; figurative light to meaning notes, never drawn.

**P3. Location lighting plan** [§5.3], exactly:
```
LOCATION: <name>                 TIME/WEATHER: <...>
STORY JOB OF THIS PLACE: <one sentence: what the place means>
SOURCES (story world): <each source, color temperature, hard/soft, direction>
NEUTRAL WHITE: <which source reads as plain white; all others described as warmer or cooler>
KEY RULE: <where the key comes from for most shots>
CONTRAST: <low / medium / high / extreme>   FILL: <none/low/medium/high>
WHAT STAYS DARK: <areas the audience must not see clearly>
PALETTE: <dominant hue(s)> + ACCENT: <motif color(s) allowed here>
LIGHT CUES: <script-caused changes in light and when they happen>
CONTINUITY LOCKS: <things that must not change between shots>
```
Temperatures [§4.1, approximate]: candle/oil lamp/fire 1,800-2,000 K; low-pressure sodium ~1,800 K (other colors go grey-brown); high-pressure sodium ~2,000-2,200 K (slight green); household bulb ~2,700 K; film tungsten 3,200 K; cool-white fluorescent ~4,000 K (green tint); white LED streetlight ~3,000-4,000 K; noon daylight ~5,600 K; LED flashlight 5,000-6,500 K; overcast 6,500-7,500 K; open shade 8,000 K+. Blue night is a convention and may be broken.

**P4. Color script** [§8.2-8.3]. Row fields, exactly: `# / Sequence` | `Story value change` | `Frame value (1-5)` | `Saturation (1-5)` | `Temperature` | `Dominant` | `Accent / motif` | `Key source` | `Contrast` | `Out`. Steps: (1) list sequences and story value changes; (2) mark intensity peaks; (3) decide the color logic (oppositions, text-supplied motifs, meanings); (4) peaks first, valleys lower; (5) monotony test (Rule 20); (6) motifs only where their meaning applies; (7) one-line color arc per character.
Optional swatch strip, positive terms only: `"flat abstract color-field painting made only of soft blocks of color: mostly [dominant] at [value in words: very dark / dark / middle / light / very light], one small area of [accent], [contrast] contrast between the light and dark blocks"`. Lay out in sequence order; if figures or lettering appear, regenerate (never add "no people"). Optional thumbnail strip: one rough frame per sequence, judged only on color and value.

**P5. Per-shot spec** [§9], exactly:
```
LIGHT:  source(s) in story | key direction as a visible result (which side of the face is lit,
        high or low) | hard/soft | contrast band | backlight/rim yes/no | practicals in frame |
        what stays dark | eye light yes/no | light cue during the shot (what changes, when, why)
COLOR:  dominant hue | accent and motif (with meaning) | saturation 1-5 | frame value 1-5 |
        temperature | costume/set colors that must survive this light
WHY:    one sentence linking the choice to the beat
PROMPT: one plain-language lighting sentence for the model (Section 13)
```

**P6. Consistency across generated shots** [§13.4]: (1) paste the location lighting block unchanged into every prompt there, shot changes after it; (2) approve a key frame per location and use it as input/reference (Runway input image; Veo "Ingredients to Video"; Midjourney `--sref`); (3) keep the camera on one side of the source; (4) chain continuous shots, last frame to first frame; (5) for light control, block out in Blender (Sun Angle or Area size sets softness; kelvin in each light's Temperature field, 4.5+); never use a plain grey render as a first frame (the model keeps it grey): make it an approved still with a structure-following image model (e.g. depth-guided in ComfyUI) or restyle it video-to-video; (6) relight rather than regenerate (IC-Light for stills); (7) grade each sequence together to the key frame (DaVinci Resolve free); (8) run P7.

**P7. Four-shot probe** [§13.5]: wide, medium, close-up and reverse of one location. Check key side, dark stays dark, motif colors survive, temperature matches. Fix the lighting block, then generate the rest.

## 5. Checklists

**Scene** [§11]: every light/color word listed and used; plan names every source with temperature, direction, hardness; color-script position stated; at most one main light idea, linked to the story value change; any light cue sits at a turning point with a story-world cause; motif colors only where their meaning applies; meaningful costume/set colors survive this light; signals locally correct; a non-peak scene sits below the next peak; this scene and the two before it do not all share value, saturation and temperature (unless the script row says why).

**Shot** [§11]: key source named, side consistent with the wide; where to look clear in the first second; faces to read have eye light, others a reason; one readable element even in the darkest shot; hiding readable; matte black edged, clear objects back/side-lit; helmet faces lit, visor reflections decided; every flicker or dip has a script cause; dark skin rendered richly; one dominant hue, at most two accents; nothing lit that must be dark; WHY gives a story reason; PROMPT plain, positive, consistent, no named cinematographer.

**Mistakes** [§12]: sourceless glamour; everything evenly lit (value 4-5 throughout); too dark to follow; teal-and-orange default; color shouting the theme; on-the-nose sync (light changes on the line that states it: offset a beat); inconsistent motif; motif wallpaper; stock clichés (lightning at revelation, flickering hospital tubes, god rays, candles for romance, sickly green, cold blue monster shift; test: a WHY line pasteable into any film is stock); unnamed "cinematic/moody"; key flip; time-of-day drift; surface-times-light failure; wrong local color; villain always split-lit; contradictory prompt words; **AI house look** (unasked light shafts, rims, bokeh, wet floors, teal-and-orange: write "clear air", "dry concrete floor", "background in focus", "flat even light from the ceiling panels").

## 6. Saying it to AI models

Basis: vendor guides (Veo 3.1, Runway Gen-4, Kling, Midjourney; checked 2026-09-27) plus practitioner reports, not controlled tests; confirm with P7.

- **Follow well** [§13.1]: named sources and conditions (Veo: "The scene is lit by the harsh fluorescent overhead lights and the green glow of the monochrome monitor"); simple quality and direction words (soft, harsh, warm, cool; side lighting, backlighting, overhead, uplighting); silhouette, rim, haze, lens flare (over-applied: only where needed); color attached to objects ("a small red tag on a grey steel gate", not "red accent"); "desaturated".
- **Partly** [§13.2]: direction (ignored or mirrored: add the shadow result; never "camera left"); low-key/high-key (add structure); chiaroscuro/Rembrandt (may go oil-painting: add "photographic, realistic film still"); catchlights (rarely held in video); in-clip light cues (one clip per state and cut, or first/last-frame control); moving sources (one slow source per clip, state where the pool starts and ends); flicker in dark clips (regenerate or deflicker).
- **Ignored or misread** [§13.3]: kelvin, ratios, stops (say "warm orange lamplight"); rig words (negative fill, bounce, motivated); "practical"; negative phrasing ("no blue" can add blue); "torch"; named cinematographers; hex codes (use a reference image); contradictions: one dominant temperature, and where two are needed say which dominates ("warm lamplight on both faces; a thin strip of cold blue from the window behind them"). Never "cinematic", "epic", "blockbuster" [§4.8].
- **Verdicts** [§13.3a]: "single hard light from camera left" → "One hard light from the left side of the frame; crisp shadows; the right half of his face in deep shadow." "practical lamp" → "A table lamp, switched on, visible in the frame; it is the only light in the room..." "low-key" → "Mostly dark frame; one pool of light on her hands and the tag; the rest falls to near black." "rim light" → "A thin line of light along his shoulder and hair from the window behind him" (only where a source is behind).
- **Phrasebook** [§13.6, selection]: "a tall black figure seen against a slightly lighter wall, a thin line of light along its shoulders and head"; "faint, soft flashes of blue light on the ceiling, coming through frosted windows"; "her face inside the helmet lit softly by the green glow of the display on her visor; the visor glass clear, with only a faint reflection"; "a white pressure suit with visible seams and fabric texture, not glowing"; "a dim hospital room at night, low even light, every corner of the room visible". **True black: do not generate; cut to black in editing** (generated black has noise, shapes or glow).

## 8. Conflicts and open questions

- **Numbering.** B2's 23 color-script sequences vs A3's 30 headings: map them.
- **Ex1 direction.** B2 lights the bolt-hole insert from frame-right; the B1 digest's Ex1 prompt says "torchlight from the left" (and "torch", which B2 bans). Pick one side; write "flashlight".
- **Mirror phases vs key side.** R21 assumes one reversal; B1 and A3 describe phases A/B/C, a second turn and flip-the-clip methods, and a flipped clip flips the key side (R20). Reconcile or skip R21.
- **"Out" vs A4.** `out` overlaps A4's `transition_out`; count B2's blacks against A4's cap of two editor-made blacks.
- **Motif ownership.** B2's motif table overlaps B4 and B5 (costume color) and A3 R23 (first-occurrence light as template). Choose an owner.
- **Tools.** Relighting, references and first/last-frame features change fast (defers to C1/C2); Blender Temperature field (4.5+) and grey-render advice should match C4's kit.
