# Using ChatGPT

## What it looks like

```
You:      Break down my story.        (with The Catch attached)
ChatGPT:  Hello. I'll turn The Catch into a scene-by-scene plan for making it as a film,
          including with AI picture and video tools.
          Here is one finished moment from your story ... Scene 10, shot 150 ...
          One question first:
          1. Is this story yours, or do you have permission to adapt it?   [It's mine]
You:      defaults
```

ChatGPT Plus can run Stage's tools in its own workspace, so it checks every piece with the checker program, just as Claude does. You set up one project for your film, once, and download a save file at each stop.

## What you need

- ChatGPT Plus or higher. A project on Plus holds up to 25 files; the kit uses 12, plus the text for the instruction box.
- The folder `Chat kit`, in `03 Kits to upload` in Stage.

## First, privacy

Do this once, before you upload a story that is not published: open **Settings**, then **Data controls**, and turn off **"Improve the model for everyone"**. The AI asks you once whether it is off and writes your answer into your project.

## Set up a project, once for each film

1. Make a project (**Projects**, then **New project**) and name it after your story. If ChatGPT asks about memory, choose the memory that stays inside this project.
2. Open the project's instructions and paste the whole of `00 Paste into instructions.txt` from `Chat kit`. It is under 6,000 characters, so it fits.
3. Add the other 12 files of `Chat kit` to the project's files, `07 Tools.zip` included. ChatGPT takes 10 files at a time, so add them in two goes.
4. In the model picker, choose **Thinking**. The quicker model cannot hold a whole story at once.

If your app shows different names for these menus, follow the app: the makers move them from time to time.

## The first message

In a new chat in the project, attach your story and type:

```
Break down my story.
```

ChatGPT unzips `07 Tools.zip` in its workspace, tests what it can do there, and then shows you one finished shot from your story and one question. If it says it cannot find `07 Tools.zip`, attach that file to your message too.

## Saving: download at once

ChatGPT's workspace is emptied when a chat sits idle for a while, and its download links expire. So at every stop ChatGPT makes one **save file**, a ZIP named like `023 Save - The Catch - after scene 10.zip`, and says:

```
Download it now: the link expires.
```

Download it straight away and keep all your save files together in one folder on your computer. The newest save file holds the whole project so far; the number at the front grows with every save. If a link has already expired, type **Make the save file again.**

## Carrying on another day

Start a new chat in the same project, attach the newest save file, and type:

```
Continue my breakdown.
```

ChatGPT opens the save file, reads `00 Start here` and tells you in one line what comes next.

## When the chat gets long

One chat does one group of scenes. When a chat gets long, or ChatGPT says it is summarising earlier messages, it finishes the piece it is on, makes a save file and says: "This chat is getting long. Start a new chat in this project, attach the save file, and type: Continue my breakdown." Do just that; nothing is lost.

When you reach your plan's usage limit, ChatGPT slows down or stops for a few hours. Your save file keeps everything; carry on later with the same message.

## What works here

Everything except grey previews, which need Claude Code on your computer (02 Using Claude). Storyboards, prompts for AI video and the edit plan all work: type **Make storyboards**, **Get it ready for AI video** or **Plan the edit** when the breakdown is finished.

The checker runs in ChatGPT itself, so you do not need the check on the Claude website that Gemini users need.

## If something looks wrong

- ChatGPT's reply stops in the middle: type **continue**. It sends the cut part again.
- ChatGPT says it cannot run code in this chat: start a new chat in the project and try again. If it still cannot, it works the way a chat app without code does, with files you save by hand: follow **04 Using Gemini or another chat app** from "Saving".
- You want to change something: say it in your own words. ChatGPT says what it touches, asks once if it is costly, and redoes only that.

The full list of what you can type is in **05 How to read your breakdown**.
